# Главная «Надеждика» — реализация 2 ноября 2026

Локальная статическая главная готова к просмотру. Сборка `dist/` пересоздаётся из
`index.html`, `src/` и `public/`. Runtime-зависимостей и внешних шрифтов нет.
Команды: `npm run dev`, `npm run check`, `npm run build`, `npm run preview`.

## Содержание и источники

Бриф — PRODUCT.md, направление — DESIGN.md. Пять направлений, возраст футбольных
программ, описание английского, хореографии, подготовки к школе и социального проекта
сверены с [действующим сайтом](https://nadezhdik.ru/) 2 ноября. Телефон взят из брифа
и повторно найден на сайте. Условия, набор, цены и команда не выдумывались.
Площадки обозначены с ограничениями достоверности из брифа.

Каждый раздел отвечает на вопрос из DESIGN.md. Контактный блок заменяет пока не
согласованную серверную заявку рабочими ссылками на телефон и сообщения сообщества.
Сайт не показывает фиктивную отправку; текст обращения копируется только по действию
пользователя, затем пользователь самостоятельно отправляет его во ВКонтакте.

Запрошенные референсы открывались в Playwright: https://www.iszl.ch/ — ERR_TIMED_OUT,
https://format.obys.agency/ — HTTP 403. Текстовое содержимое обеих страниц получено
через web. Полноценный визуальный осмотр и проверка их прокрутки недоступны в сессии.
`iszl-unavailable.png` сохраняет ошибку браузера. Использованы заданные пользователем
принципы взаимодействия и движения, без утверждения о точном воспроизведении эффектов.

## Производные материалы

`public/images/penguin-welcome.webp` и `football.webp` скопированы из существовавшего
незакоммиченного `dist/images/`. Это оптимизированные версии оригиналов из
`assets/references/nadezhdik/originals/`: приветственный пингвин и футбольная иллюстрация.
URL оригиналов и их хеши сохраняются в основном asset-manifest.json. Иллюстрации
используются для образа бренда, а не как фотографии реальных занятий.
`wordmark.svg` — существовавшая производная с заливкой #17232b, очертания сохранены;
`penguin-face.svg` — исходный знак. Новых изображений и промптов нет.

Локальный `public/fonts/golos-text.woff2` (около 76 KB) взят из существовавшего черновика;
рядом сохранена OFL. В браузере подтверждены загрузка семейства и отображение кириллицы.
Два растра суммарно занимают около 184 KB. Все материалы с текущими размерами и SHA-256
перечислены в `assets.json`. Права на публичное использование брендовых материалов
предстоит подтвердить согласно исходному реестру; текущая работа — локальная реализация.

Предыдущий незакоммиченный `dist/` сохранён перед первой пересборкой в
`/tmp/nadezhdik-dist-before-homepage-20261102`. Уже имевшиеся удаление academy-banner.svg
и изменение основного asset-manifest.json не изменялись в рамках этой работы.

## Выполненные проверки

- `npm run check` и `npm run build` — успешно. В production-сборке нет ошибок
  консоли, отсутствующих изображений и HTTP-ошибок ресурсов.
- Playwright: 390×844, 1366×768, 1920×1080 — сохранены и просмотрены начало, середина,
  конец. Файлы `phone-*`, `laptop-*`, `wide-*`. Проверены фактическая загрузка шрифта,
  переносы, размеры иллюстраций, читаемость. Горизонтального переполнения нет.
- Дополнительно 320, 768 и 1024 px: scrollWidth равен ширине viewport.
  Также просмотрен reflow 683×384 — эквивалент доступной CSS-области ноутбука
  1366×768 при 200%; мобильное меню доступно, переполнения нет.
- Все пять раскрытий работают клавиатурой Enter и обновляют иллюстративное поле.
  English N club подставляется в контактный select и в текст обращения.
- Успешное копирование проверено чтением буфера. Отказ Clipboard API проверен
  принудительным отклонением: показано сообщение о ручном копировании, текст сохранён.
- Мобильное меню раскрывается и закрывается после выбора ссылки. Skip-link получает
  видимый фокус; якорные ссылки имеют существующие цели. Внешние ссылки открываются
  с `noopener noreferrer` и доступной подписью о новой вкладке.
- Reduced motion: ноль активных анимаций, `animation-name: none`, `scroll-behavior: auto`.
  При обычном режиме изменение transform строки после прокрутки подтверждено.
- Без JS в отдельном контексте браузера читается страница, нативно раскрывается N DANCE,
  доступны телефон и ВКонтакте; сообщение об ограничении подбора отображается.
- По пути `/dist/` проверены загрузка страницы, шрифта и героя с относительными URL.
- Контраст основных пар сохранён из DESIGN.md. Для голубых текстовых акцентов используется
  более тёмный #0076a8. На фирменном оранжевом — тёмный текст, на тёмном — белый.

## Автоматические дизайн-проверки и решения

Taste inspector запускался дважды; в первом проходе выявил реальное переполнение,
малый шрифт и слишком тесный трекинг. Они исправлены. Финальный `taste-inspect.txt`
содержит 9 FAIL и 4 WARN по эстетическим правилам скилла; это не успешный gate.
Согласно AGENTS.md они оценены относительно брифа:

- Многострочные крупные заголовки сохранены: это композиционный приём, переносы просмотрены.
- Город и возрастные подписи сохранены как полезные сведения при выборе.
- Счётчик в превью показывает выбранное направление из пяти, а не номера разделов.
- Линии отделяют интерактивные строки, граница select нужна для распознавания поля;
  тень мобильного меню отделяет плавающий слой от страницы.
- Квоты на число картинок и движущихся элементов не применяются. Реальных фотографий
  с подтверждёнными правами нет; добавление случайных материалов ухудшило бы достоверность.
- Вторичный цвет используется для пояснений, основной текст остаётся тёмным.
  Разные размеры отражают роли и адаптацию, отсутствие видео осознанно.

Impeccable context успешно вызван; detect выполнен один раз после первой сборки,
результат `impeccable-detect.json` содержит предупреждения. Найденные мелкие подписи
впоследствии увеличены до 13 px. Предупреждения об отступах сопоставлены с реальным
рендером: padding-block и вложенный контейнер обеспечивают поля; декоративная строка
намеренно выходит за границы своего обрезающего контейнера. Повторный detect не выполнялся.
Taste lint сохранён отдельно; его стилистические ограничения не объявляются пройденными.

Визуальная оценка: герой и открытый каталог формируют главную иерархию; оранжевый
раздел меняет масштаб; площадки и социальный проект имеют самостоятельные форматы.
В первом проходе исправлены переполнение, мелкие подписи и трекинг. Числовую оценку
«премиальности» и неопределимость происхождения не заявляем.

## Ограничения и инструменты

До публичного запуска нужны согласованный канал серверных заявок и правовые тексты,
подтверждение условий, площадок и прав на материалы. Полная отправка заявки в CRM
не реализована и не тестировалась. Внешние сообщения не отправлялись.
Реальный телефон, GPU-профилирование и полная WCAG-аудиторская проверка не выполнялись.
CSS zoom не равен браузерному увеличению: сохранённый `zoom-200.png` — диагностический
кадр CSS zoom, не доказательство успешного браузерного zoom; reflow проверен отдельно.

В проекте уже установлены локальные Taste, Impeccable и Emil. Прочитаны Taste,
Impeccable layout/polish и Emil Animate; вызваны Impeccable context/detect,
Taste inspect/lint. Использованы Playwright MCP, web и локальный просмотр изображений.
Новых инструментов, агентов, hooks и расширений не регистрировалось. Imagegen не вызывался;
существующих растров хватило. Публикация и хостинг не настроены.
