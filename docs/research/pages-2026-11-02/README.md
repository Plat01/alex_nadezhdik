`npm run check`, `npm run build` и `git diff --check` выполнены успешно.
Production-сборка проверена локально по подпути `/dist/`: относительные ссылки
на CSS, JS, изображения и шрифт загружаются без ошибок HTTP.

не считаются ошибкой загрузки: они запрашиваются при показе соответствующего блока.
Проверены мобильное меню, переход к направлениям, раскрытие английского клавишей
Enter, подстановка направления и текста обращения, локальные якоря.
При reduced motion активных анимаций нет, прокрутка `auto`.

об ограничении выбора направления. Ошибок JS/консоли и HTTP-ошибок ресурсов нет.
Машинный результат — `checks.json`.

через уже установленную библиотеку Playwright из окружения `val_store` в отдельном
временном Chromium; зависимости проекта и существующие браузерные сессии не менялись.

после проверки живого URL. Этот документ фиксирует локальную проверку до deploy.
